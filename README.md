# Фильмотека (Film Library)

React-приложение для поиска и просмотра информации о фильмах с использованием открытого API Кинопоиска.

>Приложение работает с внешним API, а не с собственным сервером. Поэтому все данные, вводимые в формы поиска или фильтрации, не отправляются на сервер и не сохраняются в базе данных, а используются только для формирования запросов к API.

## О проекте

Это учебный проект в Забайкальском государственном университете, созданный для отработки навыков работы с современным стеком технологий React. 
Он представляет собой приложение с маршрутизацией, которое позволяет пользователям искать фильмы и просматривать их детальную информацию.

### Основной функционал

$`\color{yellow}*`$ **Поиск фильмов:** поиск через API Кинопоиска;<br>
$`\color{yellow}*`$ **Пагинация:** навигация по страницам с результатами поиска;<br>
$`\color{yellow}*`$ **Просмотр деталей:** переход на отдельную страницу с подробной информацией о выбранном фильме;<br>
$`\color{yellow}*`$ **Маршрутизация:** навигация по страницам приложения с помощью React Router.
