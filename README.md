# Фильмотека (Film Library)

Пробное React-приложение для поиска и просмотра информации о фильмах с использованием открытого API Кинопоиска.

## О проекте

Этот проект был создан в учебных целях для отработки навыков работы с современным стеком технологий React. 
Он представляет собой приложение с маршрутизацией, которое позволяет пользователям искать фильмы и просматривать их детальную информацию.

>Приложение работает с внешним API, а не с собственным сервером. Поэтому все данные, вводимые в формы поиска или фильтрации, не отправляются на сервер и не сохраняются в базе данных, а используются только для формирования запросов к API.

### Основной функционал

*   **Поиск фильмов:** поиск через API Кинопоиска;
*   **Пагинация:** навигация по страницам с результатами поиска;
*   **Просмотр деталей:** переход на отдельную страницу с подробной информацией о выбранном фильме;
*   **Маршрутизация:** навигация по страницам приложения с помощью React Router.

## Используемые технологии

*   [React](https://reactjs.org/);
*   [Vite](https://vitejs.dev/);
*   [React Router](https://reactrouter.com/);
*   [Material UI (MUI)](https://mui.com/).
